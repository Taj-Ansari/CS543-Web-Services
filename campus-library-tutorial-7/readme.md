# Campus Library

Tutorial 7 for the Web Services course. This project provides a GraphQL API for authors and books using PostgreSQL.

## Run the project

1. Install dependencies:
   ```bash
   npm install
   ```
2. Add your PostgreSQL connection settings to `.env`:
   ```env
   DB_HOST=localhost
   DB_PORT=5432
   DB_NAME=campus_library
   DB_USER=your_postgres_username
   DB_PASSWORD=your_postgres_password
   ```
3. Start the server:
   ```bash
   npm start
   ```
4. Open `http://localhost:4000/` to use the GraphQL API.
